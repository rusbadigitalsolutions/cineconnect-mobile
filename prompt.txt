## 1. PROJECT OVERVIEW & ARCHITECTURE

CineConnect is a high-performance, real-time social networking, job matching, talent contest, marketplace, and training portal for the film industry (Actors, Crew Members, Casting Directors, and Producers). 

This prompt specifies the complete native mobile version of CineConnect. The mobile client must be built using React Native with Expo (Expo SDK 50+), Expo Router (or React Navigation v6), and NativeWind (Tailwind CSS v4-compatible). It must share the exact Firebase schemas, auth database, and real-time synchronizations as the CineConnect web app.

### Core Technology Stack:
- **Framework**: React Native with Expo (Managed Workflow)
- **Styling**: NativeWind (Tailwind CSS utility styling adapted for Native React components)
- **Navigation**: Expo Router (File-based navigation) or React Navigation Bottom Tabs + Stacks
- **Database/Auth SDK**: Firebase JS SDK v9+ or `@react-native-firebase` (native libraries)
- **Special Libraries**:
  - `expo-image-picker` (Media picking & direct uploading)
  - `expo-notifications` (Registering tokens, scheduling, and displaying push notifications)
  - `react-native-webview` (Secure web-view wrapper for Paystack transactions & video reel previews)
  - `lucide-react-native` (Consistent vector iconography)

5. NATIVE MOBILE PERFORMANCE & CAPABILITIES
A. Expo Push Notifications Setup
The mobile app must register and manage push notifications using the pattern below:

import * as Notifications from 'expo-notifications';
import * as Device from 'expo-device';
import { doc, updateDoc } from 'firebase/firestore';
import { db } from './firebase';

Notifications.setNotificationHandler({
  handleNotification: async () => ({
    shouldShowAlert: true,
    shouldPlaySound: true,
    shouldSetBadge: false,
  }),
});

export async function registerForPushNotificationsAsync(userId: string) {
  let token;
  if (Device.isDevice) {
    const { status: existingStatus } = await Notifications.getPermissionsAsync();
    let finalStatus = existingStatus;
    if (existingStatus !== 'granted') {
      const { status } = await Notifications.requestPermissionsAsync();
      finalStatus = status;
    }
    if (finalStatus !== 'granted') {
      console.warn('Failed to get push token for push notifications!');
      return;
    }
    token = (await Notifications.getExpoPushTokenAsync()).data;
    
    // Save token to User Profile in Firestore
    const userDocRef = doc(db, 'users', userId);
    await updateDoc(userDocRef, { pushToken: token });
  } else {
    console.log('Must use physical device for Push Notifications');
  }
  return token;
}
